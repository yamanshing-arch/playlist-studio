Privacy Policy & Data Disclosures

1. YouTube API Services & Third-Party Terms

Playlist Studio connects directly with YouTube API Services. By utilizing this service, users acknowledge and agree to be bound by the YouTube Terms of Service and the Google Privacy Policy.

2. Information Collection, Storage & Device Access

Playlist Studio operates entirely within the user's browser client. We do not operate an external database or tracking server, and we never collect, store, or sell personal identifiable information.

  • OAuth Access Tokens: Ephemeral authentication tokens issued by Google Identity Services are stored locally on the user's device in browser localStorage to maintain session state across reloads.
  • Local Cache & Playlist Identifiers: Tracked source playlist IDs and video sequence order are stored on the user's device solely to enable chronological sorting and Delta Sync updates.
  • No Tracking Cookies: The application does not deploy advertising or cross-site tracking cookies.

3. Data Retention & Policy Compliance (Under 30 Days)

In compliance with YouTube API Developer Policies, all API-retrieved content, channel statistics, and video metadata are requested ephemerally in real-time. No API data is persisted for more than 30 days. Disconnecting your account or clearing your browser cache immediately purges all local storage tokens.

4. Revoking Access & Security Controls

Users may revoke Playlist Studio’s access to their Google and YouTube account permissions at any time via the official Google Security Settings (Permissions) portal.

Client ID & 100k Quota Guide

YouTube Data API provides 10,000 units/day per project. Reading/searching playlists costs almost zero (1 unit per 50 videos), while inserting a video into your library costs 50 units (~200 videos total per day). Setting up your own project provides an isolated quota pool.

🤖 Interactive Gemini Setup Assistant

Want step-by-step guidance through Google Cloud? Click below to have Gemini guide you with exact instructions tailored for Playlist Studio.

Step 1: Create OAuth Client ID

  1. Open the Google Cloud Console and create a project.
  2. Go to APIs & Services → Library, find YouTube Data API v3, and click Enable.
  3. Under OAuth consent screen, select External, complete the details, and add your email under Test users.
  4. Go to Credentials → Create Credentials → OAuth client ID.
  5. Select Web application. Under Authorized JavaScript origins, add this site's exact root origin (e.g. https://yamanshing-arch.github.io without trailing slash).
  6. Copy the Client ID, paste it into the drawer menu, and click Save & Apply.

Step 2: Request Quota Extension (100,000)

  1. In Google Cloud Console, navigate to IAM & Admin → Quotas & System Limits.
  2. Filter for YouTube Data API v3 and find Queries per day.
  3. Click Edit Quotas, select 100,000 units.
  4. Describe the use case: "Personal marathon and multi-perspective collaboration organizer combining chronological series and creator viewpoints."

About Playlist Studio

💡 Why was this created?

YouTube does not allow users to combine multiple playlists, sort video runs chronologically into proper binge orders, or merge cross-channel multiplayer POV perspectives. Playlist Studio eliminates that friction, letting you organize, filter, deduplicate, and compile sequential marathons straight to your personal YouTube account.

⚡ Core Capabilities

  • Intelligent Ordering: Sort collections by release date so episodic series play in chronological order.
  • Collab POV Detection: Cross-references collaborator links in video descriptions to weave alternating viewpoints into a single master marathon.
  • Delta Sync: Check linked source playlists for newly uploaded videos and append only the new episodes without regenerating.
  • Automatic Batch Splitting: Automatically sections oversized marathons into sequential Part 1, Part 2, etc.
  • Quota Guard: Real-time cost estimation and safety controls protect your daily YouTube quota limits.

📖 How to Use Playlist Studio

1. Combine Existing Playlists

Select two or more playlists in My Library, name your new collection, choose an order, and tap Combine Playlists. The app merges all episodes into a brand-new YouTube playlist in your account.

2. Episode Binging & Chronological Order

YouTube channels often autoplay backwards. Use the 📅 Oldest button in the Creator Explorer to arrange series from the first episode to the latest. Tip: If a series has more than 50 episodes, click Load More Episodes until all are loaded before clicking Oldest to sort the entire series chronologically.

3. Sequence Shaping Tools

  • ⇅ Invert: Reverse the current screen sequence with one tap.
  • 🔀 Shuffle: Randomize the queue for variety marathons.
  • Strip Filter: Type a keyword like #shorts or trailer and press Strip to discard matching items in bulk.

4. ✨ Collab Multi-POV Series Sync

When gaming groups record multiplayer sessions, click the ✨ Collab Multi-POV button on any playlist card. The app inspects video descriptions, discovers collaborator playlist links, and merges all perspectives into a unified chronological master series.

5. Smart Delta Sync

Playlists created here are linked to their sources. When a creator uploads new episodes, tap 🔄 Check for New Videos in your library to append only the newest uploads—saving API quota without remaking the entire list.
