Client ID & 100k Quota Guide

By default, the YouTube Data API provides 10,000 units/day per project. Adding one video costs 50 units (~200 videos total). Use your own project to get an isolated quota pool or request an increase to 100,000 units.

Step 1: Create OAuth Client ID

  1. Open the Google Cloud Console and create a project.
  2. Go to APIs & Services → Library, find YouTube Data API v3, and click Enable.
  3. Under OAuth consent screen, select External, complete the required details, and add your email under Test users.
  4. Go to Credentials → Create Credentials → OAuth client ID.
  5. Select Web application. Under Authorized JavaScript origins, add this site's exact URL.
  6. Copy the Client ID, paste it into the drawer menu, and click Save & Apply.

Step 2: Request Quota Extension (100,000)

  1. In Google Cloud Console, navigate to IAM & Admin → Quotas & System Limits.
  2. Filter for YouTube Data API v3 and find Queries per day.
  3. Click Edit Quotas and apply for a higher quota limit.
  4. Request 100,000 units.
  5. Describe the use case: "Personal playlist marathon organizer creating sequential and episodic series."

About Playlist Studio

💡 Why was this created?

YouTube does not allow users to combine multiple playlists or sort video runs chronologically into proper episode binge orders. Playlist Studio eliminates that friction, letting you organize, filter, deduplicate, and sort playlist marathons straight to your personal YouTube account.

⚡ Core Capabilities

  • Intelligent Ordering: Sort collections by release date so series play in chronological story order.
  • Delta Sync: Check linked source playlists for newly uploaded videos and append only the new episodes without regenerating.
  • Automatic Batch Splitting: Automatically sections oversized marathons into sequential Part 1, Part 2, etc.
  • Quota Guard: Real-time cost estimation and safety controls protect your daily YouTube quota limits.
